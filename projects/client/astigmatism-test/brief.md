# Gzenaya Optique / Vision test reel (astigmatism-test)

Opened 2026-10-07. Sources (Drive folder "VID 4 test 10"): C2430 (20.2 s),
C2437 (22.6 s), C2438 (6.2 s). Sony 4K vertical 50 fps, lav on L, same studio.

## Client brief
- A test the viewer does on the spot: dead simple, makes the scroller stop,
  do the test, and replay (loop).
- Brief first; edit on "go".

Note: the script describes the tumbling-E test (direction of the letter E,
visual acuity), not the astigmatism clock-dial (radial lines).

## Proposed edit (~25-28 s, built to loop)
- Hook 0-5 s: frame 1 already shows the test card + "STOP ✋ دير التست" + 10 s badge.
- How-to 5-17 s: four pictogram steps on his words (phone ↔ 3 m, E turning
  ⬅️➡️⬆️⬇️, eye closing, "4 E" counter).
- Test 17-25 s: full-screen chart, 4 E of decreasing size in random directions,
  right eye 4 s → switch → left eye 4 s, countdown + ticking SFX.
- CTA 25-29 s: comment box typing an example answer + save.
- Loop: last frame = first frame (test card).
